# Zufallszahl erraten

Ein Spiel, in welchem eine zufällige Zahl zwischen 1 und 100 generiert wird und der Spieler diese erraten muss. Nach jedem Versuch erhält der Spieler Feedback, ob die gesuchte Zahl höher oder niedriger liegt.

[Projektseite](https://smstark-projekt.de/projekte/zufallszahlerraten.html) | [Downloads](https://smstark-projekt.de/downloads.html)
